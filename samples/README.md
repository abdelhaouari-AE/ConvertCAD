# Sample drawings

| File | Content |
|---|---|
| `sample_plan.pdf` | Vector A3 formwork plan (*plan de coffrage*) at 1:100: grid axes in CENTER linetype with bubbles, 20 columns and 3 doors (→ blocks), walls, a curved wall (arc), a tank (circles), a free-form curve (spline), arrow and tick dimension chains, leaders, a notes paragraph (MTEXT), a hatch and a title block reading *Echelle : 1/100*. Sheet 2 is rotated 90° (tests `/Rotate` handling). |
| `sample_scan.pdf` | The same plan as a 150 dpi scanned image, to try tracing and OCR. |

Both files are generated by code (`convertcad/samples.py`). Re-create them with:

```bat
python scripts/make_samples.py
```

Try them:

```bat
python -m convertcad samples\sample_plan.pdf                  :: open in the application
python -m convertcad --cli samples\sample_plan.pdf -o out\plan.dxf
python -m convertcad --cli samples\sample_scan.pdf --preset scanned
```
